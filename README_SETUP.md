# Setup

1. Create a **public** GitHub repository named exactly `arushmalikk`.
2. Extract this project and upload its contents to the repository root (do not upload only the ZIP).
3. Confirm `README.md`, `scripts/`, `assets/`, and `.github/` are at the root.
4. Open the repository's **Actions** tab and enable workflows if prompted.
5. Run **Update animated profile cards** once using **Run workflow**.
6. Visit https://github.com/arushmalikk to preview your profile.

## Customize your profile
Edit the ABOUT and CURRENTLY sections in `README.md` with your real skills and current projects.

## Data accuracy
- Public repo, follower, star and fork metrics come from GitHub's REST API.
- Repository metrics cover up to the 100 most recently updated owned public repositories.
- Language distribution counts repositories by primary language, not lines of code.
- Activity bars show recent public events, not the complete contribution graph or private activity.
- The generator uses only Python's standard library. GitHub Actions supplies its built-in token.
